# Diagram sources

Run `python3 render_diagrams.py` to regenerate the three SVGs in `../assets/`. Uses the Python standard library only.

Conventions: cloud service/deployment view, crow’s-foot entity relationships, UML sequence lifelines and transaction frame. The ERD intentionally shows selected entities and declared relationships; JSON keys and historical stage IDs are not invented foreign keys.

Technology icons: Simple Icons, https://github.com/simple-icons/simple-icons (CC0; license included). Logos identify the actual technologies and do not imply endorsement.
